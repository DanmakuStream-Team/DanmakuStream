## 3. 可重复执行方法

普通测试：

```powershell
cd backend
go test ./...
```

MySQL 集成测试需要提供有权创建临时数据库的测试账号：

```powershell
$env:DANMAKU_TEST_ADMIN_DSN='<测试管理员DSN>'
go test -tags=integration ./integration -run TestEngagementUseCasesWithMySQL -v
Remove-Item Env:DANMAKU_TEST_ADMIN_DSN
```
