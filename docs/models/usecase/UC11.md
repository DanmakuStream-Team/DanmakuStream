# UC11 用户私信与媒体分享

追溯编号：`REQ11 / UC11 / SYS-SEQ11 / COMP-SEQ11 / OBJ-SEQ11 / UNIT-TC11 / INT-TC11 / E2E-TC11`

登录用户可以创建会话、发送私信，并把视频或直播内容作为媒体卡片分享给会话成员。系统校验会话权限和消息内容后持久化并通知接收者。

## 异常规则

- 未登录、不是会话成员或目标用户不存在时拒绝发送。
- 空消息、超长消息和无效媒体引用返回 `400`。
- 重复请求使用客户端消息 ID 幂等处理。
- 数据库写入失败时不发送成功通知。
