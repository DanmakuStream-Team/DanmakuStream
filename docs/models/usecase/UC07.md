# UC07 关注关系、分组、屏蔽与内容通知

追溯编号：`REQ07 / UC07 / SYS-SEQ07 / COMP-SEQ07 / OBJ-SEQ07 / UNIT-TC07 / INT-TC07 / E2E-TC07`

用户可以关注或取消关注创作者，设置分组、特别关注和屏蔽关系。新增关注或特别关注时，系统可建立内容通知订阅。

## 异常规则

- 不能关注自己，目标用户不存在时返回业务错误。
- 重复关注和重复取消必须幂等，不产生重复关系。
- 屏蔽关系保存后，相关交互和通知按规则受限。
