# UC13 平台审核、权限、运营与基础设施管理

> 追溯编号：REQ13 / UC13 / SYS-SEQ13 / COMP-SEQ13 / OBJ-SEQ13 / UNIT-TC13 / INT-TC13 / E2E-TC13

## 1. 基本信息

- 用例编号：UC13
- 需求编号：REQ13
- 用例名称：平台审核、权限、运营与基础设施管理
- 主要参与者：审核员、管理员
- 次要参与者：普通用户
- 前置条件：
  1. 操作者已经登录。
  2. 操作者拥有 moderator 或 admin 角色。
  3. 后端服务和数据库正常运行。
- 后置条件：
  1. 审核结果、用户角色或运营内容被保存。
  2. 最新管理结果可以在后台页面查询。
  3. 未授权操作不会修改系统数据。

## 2. 主成功流程

### 2.1 内容审核

1. 审核员登录后台。
2. 系统验证 JWT 和用户角色。
3. 审核员查看待审核视频或弹幕。
4. 审核员通过或拒绝视频，或者屏蔽违规弹幕。
5. 系统校验操作权限和请求参数。
6. 系统更新视频审核状态或弹幕屏蔽状态。
7. 系统返回处理结果。
8. 后台页面展示最新状态。

### 2.2 用户角色管理

1. 管理员进入用户管理页面。
2. 系统返回用户列表。
3. 管理员将用户角色修改为 user、moderator 或 admin。
4. 系统校验角色值。
5. 系统保存角色并返回更新结果。

### 2.3 平台运营管理

1. 管理员进入运营管理页面。
2. 管理员创建、修改或删除首页横幅。
3. 管理员创建、修改或删除系统公告。
4. 系统校验标题、公告内容和时间格式。
5. 系统保存运营内容并返回最新结果。

### 2.4 基础设施状态查看

1. 管理员进入基础设施页面。
2. 系统读取视频目录磁盘使用情况。
3. 系统从 `/proc/stat` 读取 CPU 使用率。
4. 系统统计当天和当月下行流量。
5. 系统统计直播间、直播观众和视频连接数。
6. 页面展示存储、CPU、流量和在线情况。

## 3. 备选与异常流程

- A1：未携带有效登录凭据，系统返回 401。
- A2：普通用户访问后台接口，系统返回 403。
- A3：审核员操作管理员专属功能，系统返回 403。
- A4：用户 ID、横幅 ID 或公告 ID 不合法，系统返回 400。
- A5：角色值不是 user、moderator 或 admin，系统返回 400。
- A6：横幅标题或公告内容为空，系统返回 400。
- A7：公告开始或结束时间格式错误，系统返回 400。
- A8：数据库查询或保存失败，系统返回 500。
- A9：基础设施指标读取失败时，系统返回当前可获取的数据，并记录指标缺失。

## 4. 业务规则

1. moderator 可以审核视频、管理违规弹幕。
2. moderator 不能修改用户角色、运营配置和平台指标。
3. admin 可以使用全部后台功能。
4. 普通用户不能访问任何后台接口。
5. 用户角色只能是 user、moderator 或 admin。
6. 横幅标题和公告内容不能为空。
7. 存储使用率达到 85% 为 warning，达到 95% 为 critical。
8. CPU 使用率达到 75% 为 warning，达到 90% 为 critical。

## 5. 可验证结果

- 审核结果刷新后保持一致。
- 被拒绝或待审核的视频不能公开播放。
- 被屏蔽弹幕不能继续公开展示。
- 用户角色修改后保存正确。
- 横幅和公告增删改后立即生效。
- 普通用户和审核员不能越权调用管理员接口。
- 基础设施页面能够展示指标及其数据来源。
