# UC01 用户注册、登录与资料维护

追溯编号：`REQ01 / UC01 / SYS-SEQ01 / COMP-SEQ01 / OBJ-SEQ01 / UNIT-TC01 / INT-TC01 / E2E-TC01`

## 范围

游客可以注册和登录，登录用户可以查询、修改自己的昵称、简介和头像。系统使用 JWT 鉴权，资料接口只允许访问当前登录用户。

## 主要参与者

- 游客
- 普通用户

## 异常规则

- 昵称为空、重复或超长时返回 `400/409`。
- 密码错误、JWT 缺失、过期或用户不存在时返回 `401`。
- 修改他人资料时拒绝请求，不接受客户端传入的目标用户 ID。
- 非法头像或资料内容返回 `400`。
