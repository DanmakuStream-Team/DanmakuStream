# UC08 创作者会员订阅

追溯编号：`REQ08 / UC08 / SYS-SEQ08 / COMP-SEQ08 / OBJ-SEQ08 / UNIT-TC08 / INT-TC08 / E2E-TC08`

创作者配置会员方案，用户选择方案创建订单并完成演示支付。订单确认成功后创建或续期有效订阅。

## 异常规则

- 用户不能订阅自己，方案必须属于目标创作者且处于有效状态。
- 订单金额必须和方案金额一致。
- 使用幂等键避免重复订单、重复支付和重复订阅。
- 支付失败、订单失效或方案不存在时不创建有效订阅。
