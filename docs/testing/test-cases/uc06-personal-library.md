# UC06 测试用例设计

> 状态说明：本文件只定义测试范围和断言。未执行的用例统一标记为"待实现/待执行"，不能提前填写通过。
> 用例说明：[docs/contributions/member-e/uc06-personal-library.md](../../contributions/member-e/uc06-personal-library.md)

## 1. 测试范围

- 个人资料库五区聚合：观看历史与进度、稍后再看、赞过的视频、收藏、下载内容。
- 服务端持久化（history / watchLater）与浏览器本地存储（liked / collections / downloads）的边界。
- 跨设备进度同步、继续观看、单项移除与整库清空。

## 2. 单元测试（UNIT-TC06）

|---|---|---|---|---|
| UNIT-TC06-01 | 进度写入校验 | 进度 <0、>视频时长、合法值 | 非法值被拒绝/截断，合法值持久化 | 待实现 |
| UNIT-TC06-02 | 历史去重与排序 | 同视频重复观看、多视频乱序 | 每视频一条最新记录，按时间倒序 | 待实现 |
| UNIT-TC06-03 | 稍后再看幂等 | 重复添加、添加后观看 | 重复添加不产生多条；观看后自动移出 | 待实现 |
| UNIT-TC06-04 | 清空逻辑 | 有数据/无数据 | 清空后各区为空且接口返回一致 | 待实现 |
